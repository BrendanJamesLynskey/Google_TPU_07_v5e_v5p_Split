# TPU v5e &amp; v5p &mdash; The Two-Track Fork

The 2023 fork of the TPU product line into "e-class" (efficient, 256-chip 2D-torus, cost-optimised) and "p-class" (performance, 8,960-chip 3D-torus + OCS, frontier training). v5e for fleet inference and modest training; v5p for Gemini 1.5 Pro 1M-context. Multislice and Pathways on Cloud explained.

**Live site:** https://brendanjameslynskey.github.io/Google_TPU_07_v5e_v5p_Split/

Part of the [Google TPUs series](https://github.com/BrendanJamesLynskey/LLMs#hardware--inference).
